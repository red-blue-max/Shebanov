# Сайт тренера по плаванию — шаблон ZABA

Одностраничный статический сайт (HTML + CSS + JS, без сборщика) для Александра Шебанова. Сделан как шаблон: контент тренера лежит в `data/coach.json`.

## Как открыть локально
- Просто двойной клик по `index.html` — работает по `file://` (данные берутся из `assets/js/data.js`).
- Или через сервер (так ведёт себя хостинг, данные из `data/coach.json`):
  ```bash
  python -m http.server 8765
  ```
  и открыть http://127.0.0.1:8765/
- `index.html?dev` — режим разработчика: показывает заглушку пустого блока «Отзывы».

## Структура
```
index.html            главная (весь основной текст в разметке — для SEO)
privacy.html          политика конфиденциальности (шаблон с плейсхолдерами)
assets/css/style.css  стили, палитра в :root
assets/js/main.js     рендер блоков из JSON, меню, квиз, FAQ, lightbox, счётчики, цели Метрики
assets/js/data.js     копия coach.json для file:// (генерируется)
assets/video/         hero.webm, hero.mp4, hero-poster.jpg — видео-фон первого экрана
assets/img/           webp + jpg, ширины 480/800/1200/1600, og-cover.jpg, favicon
data/coach.json       ВЕСЬ изменяемый контент тренера
tools/                optimize_images.py, make_logo.py, build_data.py, screens.mjs
IMAGE_CATALOG.md      какие фото куда и почему
TODO.md               всё, что нужно уточнить до публикации
_screens/             скриншоты на 360/390/768/1024/1440
```

## Как менять контент
1. Правите `data/coach.json`. Пустая строка = данных нет → на сайте жёлтая плашка `[УТОЧНИТЬ]`.
2. Запускаете `python tools/build_data.py` — обновит `assets/js/data.js` и микроразметку FAQ в `index.html`.

Из JSON рисуются: цифры (стаж, ученики), образование, опыт, достижения, шаги методики, программы, квиз, расписание с заметками, адрес, FAQ, отзывы, контакты, реквизиты. Тексты hero, «Обо мне», вступление методики и SEO-теги — прямо в `index.html`.

Когда появятся Telegram/WhatsApp/телефон, все кнопки «Записаться» автоматически начнут открывать мессенджер с текстом «Здравствуйте, Александр! Хочу записаться на занятие. Возраст ребёнка: …».

## Как сделать сайт для другого тренера
1. Скопировать папку `site/`.
2. Заменить `data/coach.json`.
3. Положить фото, прописать их в `tools/optimize_images.py` (ключ → файл, кроп, зоны размытия), запустить `python tools/optimize_images.py`.
4. В `index.html` поменять тексты hero / «Обо мне» / методики, `<title>`, description, OG, schema.org.
5. `python tools/build_data.py`.

## Проверка
- Скриншоты: запустить сервер (см. выше) и `node tools/screens.mjs http://127.0.0.1:8765/` — сохранит `_screens/*.png` и `_screens/report.json` (горизонтальное переполнение, битые картинки). Нужен установленный Google Chrome. На полностраничных снимках мобильных ширин Chrome иногда склеивает низ страницы неверно (повтор hero вместо подвала) — это артефакт съёмки; живую страницу проверял отдельно в браузере.
- Последний прогон (17.10.2026): 360 / 390 / 768 / 1024 / 1440 — горизонтального скролла нет, битых картинок нет, ошибок в консоли нет.
- **Lighthouse не запускался** (не установлен, скачивание пакетов не делал). Запустить можно в Chrome DevTools → Lighthouse → Mobile. Цель — 90+ по всем четырём метрикам.

## Видео на первом экране
- Сначала грузится только `hero-poster.jpg` (preload). Источники webm/mp4 `main.js` подключает после события `load` и только если ширина ≥ 768 px, нет `prefers-reduced-motion` и не включена экономия трафика (Save-Data / 2G). Иначе показывается poster.
- Кнопка паузы в правом нижнем углу hero появляется только вместе с видео. Вне экрана видео ставится на паузу.
- Десктоп (≥ 1100 px): текст слева, видео справа без искажений. Под текстом — затемнение 70–76 % и два слоя размытия (18 и 6 px) с плавными масками, к правой части они сходят на нет. На узких экранах размытие и затемнение по всему кадру. Контраст белого текста по кадрам видео (шаг 0,5 с): минимум 6,27 (1440), 5,56 (1120), 4,92 (768), 4,95 на poster (390) — выше AA 4,5.
- Заменить видео: положить новые файлы с теми же именами в `assets/video/`. Если меняется кадр, перепроверить контраст.
- После правки CSS/JS увеличьте номер `?v=` в ссылках на `style.css` и `main.js` в `index.html`, иначе браузеры посетителей возьмут старую версию из кэша.

## Технические заметки
- Шрифты Unbounded, Manrope, Cormorant Garamond подключены с Google Fonts (`display=swap`). Для self-hosting скачать woff2 (кириллица) в `assets/fonts/` и заменить `<link>` на `@font-face`.
- Анимации (волны, пузырьки, блики, пловец на индикаторе прокрутки) отключаются при `prefers-reduced-motion`.
- Hero-картинка: 30 КБ webp / 79 КБ jpg (лимит 250 КБ).
- Палитра в духе Real Madrid. Логотип по решению заказчика повторяет композицию герба клуба — см. риск в TODO.md. Логотип собирается из `assets/img/src/logo-source.jpg` скриптом `python tools/make_logo.py`.
- Яндекс.Метрика: сниппет закомментирован в `<head>`, цели `cta_signup`, `messenger_telegram`, `messenger_whatsapp`, `phone_click` отправляются из `main.js`.
